# Test Cases

## Базовые проверки

### 1. Проверка подсказки
- Открыть Яндекс.Браузер
- Нажать F8
- Ожидание: показывается подсказка

### 2. Проверка основного режима
- Выделить текст
- Нажать F9
- Ожидание: запускается озвучивание

### 3. Проверка альтернативного режима
- Выделить текст
- Нажать F10
- Ожидание: запускается альтернативный сценарий

### 4. Проверка логирования
- После F8/F9/F10 открыть `logs/ahk-runtime.log`
- Ожидание: записи появились

### 5. Проверка ограничения по процессу
- Переключиться в другое приложение
- Нажать F9
- Ожидание: ничего не происходит
